# tuf-campus-network-design
Design and implementation of a secure and scalable multi-campus network for The University of Faisalabad using Cisco Packet Tracer. Includes VLANs, inter-VLAN routing, RIP dynamic routing, trunking, IP addressing, redundancy, and complete network documentation.
# TUF Campus Network Design
This project presents the complete network design and configuration for The University of Faisalabad (TUF) campuses using Cisco Packet Tracer.
## Features
- VLAN Configuration
- Inter-VLAN Routing
- RIP Dynamic Routing
- Trunk Links
- IP Addressing Scheme
- Redundancy
- Multi-Campus Connectivity
- Layer 2 & Layer 3 Switching
- Network Security Basics
## Tools Used
- Cisco Packet Tracer
- Networking Devices (Routers, Switches, PCs)
- Dynamic Routing Protocols

## Project Type
BSIT 6th Semester — Computer Networks Semester Project
