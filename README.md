# TUF Campus Network Design

## Overview
This project presents the design and implementation of a secure and scalable multi-campus network for The University of Faisalabad using Cisco Packet Tracer.

## Features
- VLAN Configuration
- Inter-VLAN Routing
- RIP Dynamic Routing
- Trunking
- IP Addressing
- Redundancy
- Multi-Campus Connectivity

## Technologies Used
- Cisco Packet Tracer
- Routers
- Layer 2 & Layer 3 Switches
- RIP Protocol

## Files Included
- Packet Tracer File (.pkt)
- Final Project Report
- Network Topology Screenshots
